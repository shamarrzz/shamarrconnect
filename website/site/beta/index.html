Welcome — onboarding guide

ShamarrConnect is a self-hosted remote desktop product. During private beta, accounts and downloads are invite-only. This page is your checklist.

What you need from your invite contact
1) Download access (Cloudflare Access email invite or a one-time link)
2) An account (email + password) — self-signup is disabled
3) Optional: a device code to join a second PC to the same account without sharing the password

1. Install the app (Windows)

  1. Open the gated download page (you will be asked to sign in with the invited email):
    shamarrconnect.com/admin/get/
  2. Download ShamarrConnect.exe (installer) and run it.
  3. If Windows SmartScreen warns, choose More info → Run anyway (beta builds are not yet code-signed).

Server is preconfigured for ShamarrConnect cloud (api.shamarrconnect.com / relay). You should not need custom server settings unless told otherwise.

2. Sign in

  1. Open ShamarrConnect → Login.
  2. Enter the email and password from your invite contact.
  3. If MFA is enabled on your account, enter the 6-digit code from your authenticator app (Google Authenticator, Authy, Microsoft Authenticator, etc.).
MFA is required for hardened accounts. After password, you should see six digit boxes. If login still works with password only, turn on Account MFA in the app (next section).

3. Protect your account (MFA) — in the app

Account MFA is separate from “Security → 2FA” on a machine (device 2FA protects incoming remote sessions).

  • Account MFA — Settings → Account → Account sign-in protection (desktop) or Account MFA (sign-in) (mobile). Enable → scan QR → enter code → save recovery codes.
  • Device 2FA — Settings → Security → 2FA — optional extra protection when someone connects to this PC.

Disable needs your password + authenticator (or recovery) code. If you lose your authenticator without recovery codes, only an admin can reset MFA.

4. Connect two machines

  1. Install and sign in on both PCs with the same account (or join the second with a device code).
  2. Note each machine’s ShamarrConnect ID on the home screen.
  3. From machine A, enter machine B’s ID and connect.
  4. Same account + MFA on: each new connect asks for your authenticator code (not the remote permanent password). Quick reconnects within the session do not re-prompt MFA.

Device code (second PC without password): on a logged-in PC use the “add another device” / device code flow → enter that code on the new PC under Login → join with code.

5. Good habits during beta

  • Use a unique, strong account password.
  • Keep MFA recovery codes offline (password manager “secure note” is fine).
  • Report bugs with: OS version, what you did, what you expected, screenshots if possible.
  • Do not share your account password; use device codes for extra machines.
  • Log out on shared computers.

6. Troubleshooting

  • Wrong password — request a reset from your invite contact (admin).
  • Stuck on MFA — check phone time is automatic; try a recovery code; ask admin for MFA reset.
  • Cannot register — expected. Self-registration is disabled; you need an invite.
  • Cannot download — use the invited email for Cloudflare Access; clear cookies if the wrong account is stuck.
  • Connect fails — confirm both sides are online, IDs are correct, and firewall allows outbound connections.
