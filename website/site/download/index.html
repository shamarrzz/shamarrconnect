How it works

1
Download and run

Open the installer — no configuration needed. Your server details are pre-configured.

2
Get your 9-digit ID

ShamarrConnect assigns your device a permanent ID. Share it with anyone you want to give access.

3
Connect

Enter the remote device's ID, accept the request, and you're in — end-to-end encrypted.

Self-hosting your own server? ShamarrConnect is built on the open-source RustDesk protocol. You can run your own relay and rendezvous server — see the backend repository for setup instructions.
