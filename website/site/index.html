The remote desktop experience, without the server work.

Everything you expect from a modern remote desktop tool, with the infrastructure run for you and billing that fits how you actually budget.

End-to-end encrypted

Every session is sealed with modern cryptography. Our relay only ever sees ciphertext, never your screen or files.

Hosted, not self-hosted

No relay server to install, patch or secure. We run the infrastructure and the updates, you use the app.

Fast and lightweight

A single small app. Connections go directly between devices whenever possible, for control that feels local.

Built for real work

Unattended access, file transfer, multi-monitor support and account sync. Windows, macOS, Linux and Android.

Your sessions stay private.

Remote sessions are encrypted end-to-end between your devices. Our relay moves ciphertext and nothing else: we cannot read your screen, your files or your keystrokes. The client is open source, so you do not have to take our word for it.

  • End-to-end encryption on every session
  • Relay sees only ciphertext
  • Open source under AGPL-3.0, fully auditable
  • Server key pinning blocks impostor servers
